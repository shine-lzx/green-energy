# Nexus Energy - Green Energy Investment Platform

A modern React-based landing page for a green energy investment platform, featuring smart ROI calculator, product showcase, and company information.

## 🌿 Features

- **Smart ROI Calculator**: Calculate potential savings from solar energy investment
- **Product Showcase**: Display various solar energy solutions with pricing
- **Responsive Design**: Fully responsive layout for all devices
- **Modern UI**: Clean, professional design with glassmorphism effects
- **Interactive Elements**: Smooth transitions and hover effects

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 4.5
- **Styling**: Tailwind CSS 3.4
- **Linting**: ESLint
- **Language**: JavaScript (JSX)

## 🚀 Getting Started

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linting
npm run lint

# Preview production build
npm run preview
```

## 🎨 Design System

The project follows the Nexus Luminous design system:

- **Primary Color**: Black (#000000)
- **Secondary Color**: Forest Green (#016d35)
- **Background**: Light Gray (#f8f9fa)
- **Glassmorphism**: Semi-transparent cards with backdrop blur
